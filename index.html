这里没法加密

浏览器在 file:// 下不提供加密能力

直接双击打开的网页，浏览器会关掉 Web Crypto，加密就做不了 —— 而「不加密」意味着数据是明文，谁拿到都能看。

请改用下面任一方式打开：
① 部署到 GitHub Pages（推荐，地址是 https，手机也能用）
② 在本目录执行 python -m http.server 8000，然后访问 http://localhost:8000

不加密模式下：数据只存在本机、不会上传到 GitHub，密码只做界面遮挡。仅适合本机随便试试。

云端同步 已加密

仓库公开也没关系 —— 上传的是用你密码加密过的密文，别人打开仓库只能看到一堆乱码。 没配也能用，数据只存在本机。

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Repository access 选 Only select repositories，只勾这一个仓库
  3. Permissions → Repository permissions → Contents 设为 Read and write
  4. Token 粘到上面保存即可。Token 存在本机浏览器里，不会进仓库。

修改密码

改密码会用新密码把整份数据重新加密一遍，并自动同步到云端。 其他设备下次打开时，要用新密码才能解开。
