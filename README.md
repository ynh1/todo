# To Do

**在线地址：<https://ynh1.github.io/todo/>**

四列看板式待办清单：**想法池 → 待办 → 进行中 → 已完成**。

想到什么先丢进想法池，要做的挪到待办排顺序，然后从上往下一条条做掉。

数据用**你自己的密码加密**后存在 GitHub 仓库里。所以——

> 仓库是公开的也没关系。别人打开仓库、下载文件，看到的只是一堆密文，解不开。

---

## 安全模型（先读这段）

| | 存在哪里 | 谁能看 |
|---|---|---|
| 你的密码 | 只在你的脑子里（勾了「记住密码」则另存一份在本机） | 只有你 |
| 本机缓存 | 浏览器 localStorage，密文 | 有密码的人 |
| GitHub 上的文件 | 仓库里的 `todo.enc.json`，密文 | 拿到文件也解不开 |

锁屏上有个 **「在这台设备上记住密码」** 的勾选（默认勾上）：勾着就不用每次重输，关掉浏览器再打开会直接进去。
代价是密码会明文存在本机浏览器里 —— **公用电脑请取消勾选**。
点设置里的「立即锁定」或「清除记住的密码」可以立刻删掉。取消勾选同理，会立马删。

想交给浏览器自己管密码（Edge / Chrome 的密码管理器）→ 点锁屏下方的「改用 Edge 记住密码」，
它会把一个账号框放出来；随便填个账号名输一次密码，浏览器就会问要不要保存，以后自动回填。
纯本地应用没有账号体系，这个框是专门喂给浏览器密码管理器的。

加密方式：密码经 PBKDF2-SHA256（21 万次迭代）派生密钥，再用 AES-GCM-256 加密整份数据。
密码**不会**写进任何文件，也不会随数据上传。

**代价**：密码忘了，数据就永久解不开了。没有找回功能，这是加密本身的性质。
所以解锁之后，偶尔点一下设置里的「导出 JSON」留个备份。

（导出的备份文件是**明文**，别随手丢进公开仓库。）

## 部署到 GitHub Pages

1. 新建一个仓库（公开或私有都行），把 `index.html`、`app.js` 传上去
2. 仓库 **Settings → Pages** → Source 选 `Deploy from a branch` → 分支 `main`、目录 `/ (root)`
3. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`
4. 第一次打开会让你**设密码**——这个密码就是加密密钥，想清楚再设
5. 进设置填 GitHub 信息，任务就会自动加密同步到仓库

### 生成 Token

GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens**

- Repository access 选 `Only select repositories`，只勾这一个仓库
- Permissions → Repository permissions → **Contents** 设为 `Read and write`

Token 存在本机浏览器里，不会进仓库。

## 本地跑

直接双击 `index.html` 不行 —— 浏览器在 `file://` 下会关掉 Web Crypto，加密做不了。
页面会提示你改用下面任一方式：

```bash
# 在本目录执行
python -m http.server 8000
# 然后访问 http://localhost:8000
```

或者直接部署到 Pages（推荐，手机也能用）。

## 操作

- **添加**：顶部输入框回车，默认进「想法池」
- **排序 / 换列**：拖动卡片（手机上长按）
- **改文字**：双击标题
- **开始下一个**：把「待办」第一条推到「进行中」
- **快捷键**：`N` 聚焦输入、`/` 搜索、`Esc` 取消编辑
- **已完成**：点圆圈打勾；再点一次是「重开」

## 专注：卡片上的 10′ / 25′ / 45′

「进行中」的卡片上有一条时间行，点 **10′ / 25′ / 45′** 就开始倒计时。
全场同时只有**一个**计时 —— 在另一张卡上开始，前一个会自动让位（会提示你切到了哪儿）。

- 倒计时显示在卡片上，标签页标题也会同步，切到别的窗口也看得见还剩多久
- **暂停 / 继续 / ×** 停掉；到点会响一声，卡片自动进入 **5 分钟休息**（`跳过` 可以直接续上）
- 计时状态存在本地，关掉浏览器再回来还接着走（按结束时间算，不会走偏）

几条顺手的设计，来自「让大脑愿意启动」那套办法：

| | 在应用里长什么样 |
|---|---|
| **微启动**：目标不是做完，是打开 | 卡片挪进「进行中」时会弹一句「先做 1 分钟 —— 打开它，写一行就行」。进行中列空了也这么提示 |
| **25 分钟 + 到点起身** | 一个计时器只对应一件事；到点强制进 5 分钟休息，不是弹个提示就完事 |
| **收工留钩子** | 每张进行中的卡片底部有「下一步：____」，写一半就停在这。下次开始计时，那句钩子会被念出来 |
| **deadline** | 卡片右侧的日历图标设截止日；卡上直接显示「3 天后截止」/「逾期 2 天」，红黄两色 |

钩子和截止日都存在加密数据里，跟着 GitHub 一起同步，换设备也在。

## 推进台（push.html）—— 与看板联动

> 看板管**卡片怎么流动**（想法池 → 待办 → 进行中 → 已完成）、专注计时、收工钩子；
> 推进台管**更全面的东西**：目标一句话、验收标志、依据、目标→动作 7 步、卡在哪、复盘、日程格、想法池立项。
> 两边是同一个数据源，不是两份清单。

**入口**：看板顶栏「推进台 ↗」，或直接打开同源的 `push.html`。

### 互相促进（双向都要有，才叫联动）

| 方向 | 具体是什么 |
|---|---|
| 看板 → 推进台 | 想法池的卡片出现在「待立项」；进行中第一张自动成为「今天这一格」；`下一步` 钩子在推进台顶部显示「上次停在哪」；10/25/45′ 专注在推进台显示倒计时；已完成数量变成「燃料」 |
| 推进台 → 看板 | 「立项」把想法池卡片挪到待办 + 生成 7 步骨架 + 把第一动作写回 `下一步` 钩子；「开工」挪到进行中并真的起一个计时；「划 ✅」写复盘并挪到已完成；「卡住」把卡在哪写回钩子；「置顶」改待办顺序 |

推进台不写「另一份计划」：日程格就是看板「待办」列的顺序，验收标志 / 依据 / 复盘都挂在卡片自己的 `drive` 字段上，**跟着看板一起加密、一起同步到 GitHub、一起换设备**。

### 数据与安全边界

- 推进台**不解密、不存任务数据**。卡片快照只经 `BroadcastChannel` 在同一域名的标签页之间用**内存**传递，不落盘、不含 token / 密码。
- 推进台的所有写操作都追加到本机 `localStorage` 的 `todo.drive.pending.v1` 队列，由**已解锁的看板**用自己既有的 `moveTo` / `addItem` / `persist` / `render` 执行 ⇒ 加密与云端同步只有一份实现。
- 队列是**短暂的明文命令**：看板执行后即清空（推进台可点「清空队列」）。看板没开或锁着时命令会排队，解锁后自动补执行；失败 3 次留在队列里并标原因，不无限重试。
- 桥只开放 6 个白名单命令（挪列 / 新增 / 写钩子 / 写 drive / 置顶 / 起专注），**不开放删除、改密码、读 GitHub 配置**。
- **开多个 To Do 标签页也不会重复执行**：桥用 Web Locks 让同一时刻只有一个标签消费队列；另一个标签在密文变化后自动重新载入，两边显示一致。
- 推进台只认**第一个**连上的 To Do 标签页；它 15 秒不响应才允许换源，避免两个标签的快照来回跳。
- ⚠️ 两页必须在**同一网址**下：GitHub Pages 的 `/todo/` 与 `/todo/push.html`，或本地同一个 `http://localhost:8000` 端口（README「本地跑」那一节）。
  **实测 `file://` 双击打开时两页的 localStorage 不共享、联动不生效**，别用这个方式跑联动。

## 多设备

**密码跟着数据走，不跟着设备走。** 换设备打开不会让你重设密码，而是问你要密码。

在另一台设备打开同一个网址 → 点「已有数据？从云端恢复」→ 填仓库信息和**你原来那个密码**，
数据就拉回来了。之后这台设备解锁用的就是那个原密码。

（第一次用才是「设置新密码」。这两条路的入口都在锁屏界面下方。）
