# To Do

四列看板式待办清单：**想法池 → 待办 → 进行中 → 已完成**。

想到什么先丢进想法池，要做的挪到待办排顺序，然后从上往下一条条做掉。

数据用**你自己的密码加密**后存在 GitHub 仓库里。所以——

> 仓库是公开的也没关系。别人打开仓库、下载文件，看到的只是一堆密文，解不开。

---

## 安全模型（先读这段）

| | 存在哪里 | 谁能看 |
|---|---|---|
| 你的密码 | 只在你的脑子里 | 只有你 |
| 本机缓存 | 浏览器 localStorage，密文 | 有密码的人 |
| GitHub 上的文件 | 仓库里的 `todo.enc.json`，密文 | 拿到文件也解不开 |

加密方式：密码经 PBKDF2-SHA256（21 万次迭代）派生密钥，再用 AES-GCM-256 加密整份数据。
密码**不会**写进任何文件，也不会随数据上传。

**代价**：密码忘了，数据就永久解不开了。没有找回功能，这是加密本身的性质。
所以解锁之后，偶尔点一下设置里的「导出 JSON」留个备份。

（导出的备份文件是**明文**，别随手丢进公开仓库。）

## 部署到 GitHub Pages

1. 新建一个仓库（公开或私有都行），把 `index.html`、`app.js` 传上去
2. 仓库 **Settings → Pages** → Source 选 `Deploy from a branch` → 分支 `main`、目录 `/ (root)`
3. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`
4. 第一次打开会让你**设密码**——这个密码就是加密密钥，想清楚再设
5. 进设置填 GitHub 信息，任务就会自动加密同步到仓库

### 生成 Token

GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens**

- Repository access 选 `Only select repositories`，只勾这一个仓库
- Permissions → Repository permissions → **Contents** 设为 `Read and write`

Token 存在本机浏览器里，不会进仓库。

## 本地跑

直接双击 `index.html` 不行 —— 浏览器在 `file://` 下会关掉 Web Crypto，加密做不了。
页面会提示你改用下面任一方式：

```bash
# 在本目录执行
python -m http.server 8000
# 然后访问 http://localhost:8000
```

或者直接部署到 Pages（推荐，手机也能用）。

## 操作

- **添加**：顶部输入框回车，默认进「想法池」
- **排序 / 换列**：拖动卡片（手机上长按）
- **改文字**：双击标题
- **开始下一个**：把「待办」第一条推到「进行中」
- **快捷键**：`N` 聚焦输入、`/` 搜索、`Esc` 取消编辑
- **已完成**：点圆圈打勾；再点一次是「重开」

## 多设备

在另一台设备打开同一个网址 → 点「换了设备？用原密码从云端恢复」→ 填仓库信息和**原密码**，
数据就拉回来了。之后这台设备的密码就是原密码。
